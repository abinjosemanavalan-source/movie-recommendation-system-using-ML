# movie-recommendation-system-using-ML
Movie Recommendation System using Python and Machine Learning. The system recommends similar movies based on genre information and user rating data. # Movie Recommendation System

## Overview
A content-based movie recommendation system built using Python and Machine Learning.

## Features
- Movie recommendations
- Similarity scores
- Rating-based filtering
- Large-scale dataset support

## Technologies
- Python
- Pandas
- Scikit-learn
- TF-IDF
- Nearest Neighbors

## Dataset
- 62,423 movies
- 25,000,095 ratings

## Example Output
Toy Story (1995)

Recommendations:

Aladdin (1992)
